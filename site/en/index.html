Select a PDF from your PC. The app automatically switches to OCR mode.

  1. 01

    Select your PDF

    Click Select your own PDF. All pages are selected initially; you can narrow the range.

  2. 02

    Set up OCR

    Choose the Text language. Text OCR always runs. Enable Recognise maths & formulas only if you also want formulas recognised.

  3. 03

    Save a new PDF

    Start Process PDF with OCR. The app adds searchable text and saves a new file. Your original stays unchanged.

No browser, sign-in or capture needed. Choose New job to return to Edubase capture. If your PDF already contains text, copying or extracting it can produce duplicates.

For your PC

Power up your maths OCR.

Match formula recognition to your PC. Open Advanced settings / Performance settings to choose computing power and the number of formulas per group.

Use CPU or GPU

Automatic uses an installed, working GPU module for maths OCR. CPU – maximum performance gives maths recognition all available processing threads. Use GPU selects a compatible graphics card; text OCR continues on the CPU.

10, 20 or 30 formulas

Choose Standard (10), High (20) or Maximum (30). This sets the maximum number of formulas the GPU processes together. Larger groups need more graphics memory and are not faster on every device.

CUDA for NVIDIA RTX

Set up the optional CUDA module and enable Use CUDA. The option is available when an NVIDIA RTX card is detected. AMD and Intel use the GPU module with DirectML. Actual speed gains depend on your PC and formulas.

Tune performance, keep the quality: These settings leave image resolution, colours and recognition models unchanged. GPU and CUDA support maths OCR. Regular text recognition stays on the CPU.

Optional add-on

Bring your formulas along.

For books and your own PDFs containing fractions, roots and special mathematical symbols, you can enable additional maths recognition.

Click Set up math OCR in the app (approx. 575 MB download), then enable Recognise maths & formulas. Recognised formulas are added as invisible searchable text – e.g. σ or F/A for Ctrl+F. The page image stays unchanged.

Also attach LaTeX files to the PDF is a separate option, off by default. No attachment is needed for search.

Complex formulas are simplified; results depend on recognition and the PDF viewer. Please check results. The app does not solve exercises.

A few quick answers

Good to know.

Will the folder fill up with page images?

By default, only the PDF remains after a successful export. Working images and temporary files are deleted, including after a partial export. Stopping or encountering an error preserves them.

Can I stop and resume later?

Yes. Choose Stop → Saved pages to PDF to export pages already captured. To continue later, enable Advanced settings / Performance settings → Keep working images before exporting.

Can PDF page labels match my book?

Yes. Enter the Reader page where printed book page 1 starts in the page-numbering setting. For example, enter 37 if there are 36 Reader pages before book page 1. PDF viewers vary in how they display page labels.

Does it work on iPhone, Android or Mac?

The app is for 64-bit Windows on Intel or AMD processors. There is currently no mobile app or Mac version. You can open this website on any device.

Do I need a subscription or API key?

The app does not require a subscription or API key. Edubase capture requires your own access to the book. Your own PDFs need no Edubase account. Downloads and Edubase access require an internet connection; OCR processing runs on your PC.

What should I know before starting?

Extract the entire package before launching the EXE. The Windows app is not digitally signed. Download it from the official project release and use its SHA256SUMS.txt if you want to verify the files. Start with a few test pages; OCR can misread characters.
